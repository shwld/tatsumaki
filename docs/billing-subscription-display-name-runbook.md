# 購読の表示名の運用

story #447。方針は [ADR-0015](adr/adr-0015-project-scoped-billing.md) の 2026-11-22 追記を参照する。

## 表示

- Stripe Portal の購読一覧に、商品名の下に `<プロジェクト名> (<projectId 末尾6文字>)` が出る。
- 請求書・領収書(PDF)には出ない。商品名のみ。

## 同期と再試行

- Checkout 作成時、名前変更時、購読一覧を開いたときに、Control Plane の `syncProjectDisplayNames` を呼ぶ。差分のある有効な購読だけ更新する。
- 名前変更は同期の失敗で失敗しない。失敗した分は、オーナーが購読一覧を開いたときに直る。
- 購読を支払ったユーザーと名前を変えたユーザーが違う場合、同期は支払ったユーザーが一覧を開いたときに反映される。

## 既存購読の移行

1. 表示名導入前の購読は、オーナーが購読一覧を開くと自動で更新される。
2. 手で移行するときは、オーナーの `billingAccountId` と、そのオーナーの全プロジェクトで `syncProjectDisplayNames` を呼び、Stripe の購読の description を確認する。
3. 課金額・請求日・権利状態は変わらない。変わっていたら止めて調査する。

## 個人情報

プロジェクト名は決済事業者に送られる。プロジェクト名に機微な情報を入れないよう、利用者へ案内する。
